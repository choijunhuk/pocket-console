# Pocket Console 0.3.0-alpha.6 — 내 Switch 키·펌웨어 가져오기

본인 콘솔에서 직접 덤프한 Switch 키와 펌웨어를 앱에 가져와 `.nsp`·`.xci` 파일을 실험적으로 열어볼 수 있습니다. 별도 에뮬레이터 앱 없이 이 APK 하나로 동작합니다.

## 달라진 점

- Switch·Switch 2 탭에 **키 가져오기**(`prod.keys`, `title.keys`), **펌웨어 가져오기**(NCA 파일이 든 zip), 삭제와 현재 상태 표시를 추가했습니다.
- 키가 있으면 `.nsp`·`.xci`를 **실험적 실행 · 미검증 (사용자 키 필요)**으로 엽니다. 게임 파일은 복사하지 않고 선택한 문서를 읽기 전용으로 엽니다.
- 키 값의 길이와 형식, 펌웨어 zip의 경로·크기·항목 수를 실행 엔진에 넘기기 전에 검사합니다. 잘못된 파일은 이유를 표시하고 거부합니다.
- 가져오기가 실패하거나 앱이 중간에 종료되어도 이전에 쓰던 키와 펌웨어를 그대로 복구합니다.
- 키와 펌웨어는 이 기기의 앱 안에만 보관합니다. 화면·로그·백업·기기 이전·네트워크로 내보내지 않으며, 키를 바꾸면 실행 엔진 프로세스를 다시 시작해 메모리에서 지웁니다.
- 실물 Galaxy S24 Ultra(Adreno 750)에서 DS·3DS·Switch 홈브루 실행을 확인했습니다.

## 설치와 업데이트

Assets의 `PocketConsole-v0.3.0-alpha.6.apk`를 다운로드해 설치합니다. Android 8.0 이상 ARM64/x86_64가 대상이며, Switch 실행은 ARM64 Android 13 이상에서만 가능합니다.

이전 공식 알파와 같은 인증서, 버전 코드 9로 서명합니다. 기존 공식 앱 위에 업데이트할 수 있으며 앱을 삭제할 필요가 없습니다. **앱 삭제는 내부 세이브와 가져온 키·펌웨어를 지우므로 삭제 후 설치하지 마세요.** 개발용 APK는 서명이 다를 수 있습니다.

## 검증 범위와 제한

Galaxy S24 Ultra(Android 17, Adreno 750)에서 공식 alpha.5 APK로 3DS 홈브루의 두 화면과 A 입력, Switch 홈브루의 화면과 A 입력을 확인했습니다. 키 가져오기는 네이티브 ARM64 에뮬레이터에서 합성 키 파일이 실행 엔진까지 전달되어 거부되고 파일이 남지 않는 것까지 확인했습니다. 모델·캐시·키·zip·복구 검사, 릴리스 린트, 공식 서명·버전·두 ABI·16KB 정렬, DS 코어와 Android 릴리스 검사, 3DS 호스트 검사를 통과한 뒤 게시합니다.

실제 키·펌웨어 설치와 `.nsp`·`.xci` 게임 실행은 검증하지 않았으며 게임별 호환성을 보장하지 않습니다. Switch 2 게임 호환성, Switch 오디오, Mali·Xclipse 등 다른 GPU는 검증하지 않았습니다. 게임·닌텐도 BIOS·펌웨어·키는 앱에 포함하거나 내려받지 않습니다. 본인 기기에서 직접 덤프한 파일만 사용하세요.
