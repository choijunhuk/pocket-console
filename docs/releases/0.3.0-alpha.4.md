# Pocket Console 0.3.0-alpha.4 — 로딩 진행 상태

DS·3DS 게임을 불러올 때 파일 복사·캐시 검사 진행률, 처리 용량, 현재 단계와 경과시간을 표시합니다. 실행할 수 없는 기종은 기다려도 자동으로 준비되지 않는다는 안내를 표시합니다.

## 달라진 점

- 파일 복사와 기존 캐시 검사에는 실제 처리 바이트에 따른 백분율과 MiB를 표시합니다.
- 전체 파일 크기를 알 수 없거나 제공된 크기가 맞지 않으면 백분율 대신 처리량을 표시합니다.
- 코어 초기화·오디오 준비·첫 화면 대기에는 현재 단계와 경과시간을 표시합니다. 첫 프레임을 전달한 뒤 실행 중으로 전환합니다.
- 15초간 진전이 없으면 오래 걸린다는 안내와 라이브러리에서 취소를 요청하는 방법을 표시합니다. 응답하지 않는 파일 제공자나 코어의 즉시 종료를 보장하지는 않습니다.
- Switch·Switch 2와 엔진이 없는 3DS 빌드의 실행 불가 상태를 명확히 표시합니다.

## 설치와 업데이트

Assets의 `PocketConsole-v0.3.0-alpha.4.apk`를 다운로드해 설치합니다. Android 8.0 이상 ARM64/x86_64가 대상입니다.

이전 공식 알파와 같은 인증서, 버전 코드 7로 서명합니다. 기존 공식 앱 위에 업데이트할 수 있으며 앱을 삭제할 필요가 없습니다. **앱 삭제는 내부 세이브를 지우므로 삭제 후 설치하지 마세요.** 개발용 APK는 서명이 다를 수 있습니다.

## 검증 범위와 제한

모델·ROM 캐시·릴리스 린트, 공식 서명·버전·두 ABI·16KB 정렬, 실제 DS 코어와 Android 릴리스 검사, 실제 3DS 호스트 화면·입력·오디오 검사를 통과한 뒤 게시합니다. APK와 체크섬, 빌드 매니페스트, 공개 인증서, 서드파티 고지 및 대응 소스를 함께 제공합니다.

Android 3DS 게임 실행, 실물 기기의 성능·진동과 게임별 호환성은 별도 검증이 필요합니다. 3DS는 GLES 3.2가 필요합니다. Switch·Switch 2 실행 엔진과 DLC·업데이트 설치는 이번 APK에 포함하지 않습니다. 게임·닌텐도 BIOS·펌웨어·키는 번들하지 않습니다.
