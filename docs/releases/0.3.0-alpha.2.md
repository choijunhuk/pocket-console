# Pocket Console 0.3.0-alpha.2 — Android 알파

3DS의 검은 화면을 수정한 업데이트입니다. 실제 Azahar 코어를 사용한 Linux 호스트 검사에서 두 화면, A 버튼, 터치, Circle Pad, 오디오와 종료·재실행 검사를 통과했습니다. Android 3DS 실행은 아직 기기 검증이 필요합니다.

## 다운로드와 설치

Assets의 `PocketConsole-v0.3.0-alpha.2.apk`를 Android 휴대폰에서 다운로드해 설치합니다. 비공개 저장소이므로 접근 권한이 있는 GitHub 로그인이 필요합니다.

Android 8.0 이상 ARM64 또는 x86_64가 대상입니다. 3DS 실행에는 OpenGL ES 3.2도 필요하며 앱이 실제 그래픽 컨텍스트 생성을 확인합니다.

기존 공식 `0.3.0-alpha.1`과 같은 인증서, 더 높은 버전 코드로 서명하므로 업데이트 설치할 수 있습니다. 앱을 삭제할 필요가 없습니다. 과거 개발용 APK는 서명이 다를 수 있으며, **앱을 삭제하면 앱 내부 세이브도 지워집니다.** 자동 삭제나 자동 재설치를 수행하지 않습니다.

## 이번 변경

- 3DS 최종 화면에 불필요한 깊이 버퍼를 붙이지 않아, 뒤 프레임이 검게 가려지는 문제를 수정했습니다.
- 3DS 호스트의 실제 화면·입력·오디오 검사를 릴리스 게시 조건에 추가했습니다.
- 보관함에서 Switch 2를 직접 선택한 `.nro` 파일을 해당 기종으로 분류합니다. 자동 `.nro` 분류는 기존처럼 Switch입니다.

DS의 두 화면, 동시 입력, 아래 화면 터치, 오디오, 게임 내 저장, 세로·가로 플레이와 로컬 보관함을 유지합니다. 본체 프레임·힌지, 눌림·포커스 표시, 밝은·어두운 테마와 큰 글씨를 지원합니다.

## 검증 범위와 남은 기능

- **DS·보관함 UI:** Android 가상 기기에서 실제 화면·입력·종료·재실행을 검사합니다.
- **3DS:** 실제 코어의 Linux 호스트 검사는 통과했습니다. Android CI 기기는 GLES 3.0이라 3DS 실행은 `NOT_RUN`입니다. Galaxy S23 Ultra 등 실물 기기의 게임별 호환성·저장·성능은 미검증입니다.
- **Switch·Switch 2:** 별도 브랜치의 코어 빌드·통합 작업 중이며, 이번 APK에는 실행 엔진이 연결되지 않았습니다. 보관함 등록과 조작 미리보기를 제공합니다.
- 물리 기기의 진동·발열·장시간 성능, DSi·퀵세이브·멀티플레이·`.cia` 설치는 이번 검증 범위에 포함하지 않습니다.

## 배포 검증과 소스

서명, 버전·ABI, APK와 네이티브 ELF의 16KB 정렬, 린트, 모델·캐시 검사 및 실제 DS·3DS 호스트 검사를 거칩니다. 같은 인증서로 서명한 테스트 APK로 Android DS·UI를 확인한 뒤 게시합니다.

Assets에 APK, 체크섬, 빌드 매니페스트, 공개 서명 인증서, 서드파티 고지와 대응 소스를 제공합니다. 게임·닌텐도 BIOS·펌웨어·키는 번들하지 않습니다.
