# Pocket Console 0.3.0-alpha.5 — Switch 홈브루 실험 실행

Switch 홈브루 `.nro` 파일을 앱 안에서 실험적으로 실행합니다. 별도 에뮬레이터 앱을 설치하지 않고 이 APK 하나로 동작합니다.

## 달라진 점

- Switch 탭에 등록한 `.nro`를 **실험적 실행 · 호환성 미확인**으로 실행합니다. ARM64, Android 13 이상과 Vulkan이 필요합니다.
- 그래픽 기능 일부가 없는 기기에서는 부족한 기능 이름을 경고로 표시한 뒤 실행합니다. 초기화에 꼭 필요한 조건이 없으면 이유를 표시하고 실행하지 않습니다.
- 45초 안에 첫 화면이 나오지 않으면 실행을 중단하고 라이브러리에 이유를 표시합니다. 셰이더를 준비하는 동안에는 최대 120초까지 기다립니다.
- 실행 전에 NRO 헤더와 영역을 검사해 손상되거나 조작된 파일을 거부합니다.
- 그래픽 검사와 게임 실행은 별도 프로세스에서 진행합니다. 그래픽 드라이버 오류가 라이브러리와 DS·3DS에 영향을 주지 않습니다.
- 인터넷 권한 없이 동작합니다. 게임 안의 네트워크 기능은 연결 없음으로 처리합니다.
- `.nsp`·`.xci`는 목록 등록만 지원합니다.

## 설치와 업데이트

Assets의 `PocketConsole-v0.3.0-alpha.5.apk`를 다운로드해 설치합니다. Android 8.0 이상 ARM64/x86_64가 대상이며, Switch 실행은 ARM64 Android 13 이상에서만 가능합니다.

이전 공식 알파와 같은 인증서, 버전 코드 8로 서명합니다. 기존 공식 앱 위에 업데이트할 수 있으며 앱을 삭제할 필요가 없습니다. **앱 삭제는 내부 세이브를 지우므로 삭제 후 설치하지 마세요.** 개발용 APK는 서명이 다를 수 있습니다.

## 검증 범위와 제한

네이티브 ARM64 Android 에뮬레이터(SwiftShader Vulkan)에서 독자 작성 홈브루의 화면·A 입력, 종료와 재실행, 파일 선택기에서의 실행, 실행 중 다크 모드 전환, 손상 NRO 거부와 프로세스 분리를 확인했습니다. 모델·캐시·릴리스 린트, 공식 서명·버전·두 ABI·16KB 정렬, DS 코어와 Android 릴리스 검사, 3DS 호스트 검사를 통과한 뒤 게시합니다.

CI 에뮬레이터는 ARM64 코드를 번역해 실행하므로 Switch 화면 검사를 실행하지 않은 것으로 기록합니다. 실물 휴대폰, Switch 오디오, 상용 게임과 Switch 2 게임 호환성은 검증하지 않았습니다. x86_64 기기용 설치에는 Switch 엔진이 들어가지 않습니다. 상용 게임에는 사용자의 키·펌웨어가 필요하며, 게임·닌텐도 BIOS·펌웨어·키는 번들하지 않습니다.
