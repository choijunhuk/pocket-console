# Pocket Console 0.3.0-alpha.1 — Android 알파

휴대용 게임기 느낌의 Android 로컬 보관함과 DS 플레이어를 설치해 볼 수 있는 첫 배포입니다.

## 다운로드와 설치

1. 아래 Assets에서 `.apk` 파일을 Android 휴대폰으로 다운로드합니다.
2. 다운로드한 파일을 열고 Android의 설치 안내를 따릅니다.
3. 앱에서 **파일 가져오기**를 눌러 본인의 게임 문서를 선택합니다.

Android 8.0 이상, ARM64 또는 x86_64가 대상입니다. 하나의 APK에 두 ABI를 포함합니다. 저장소가 비공개이므로 다운로드에는 저장소 접근 권한이 있는 GitHub 로그인이 필요합니다.

## 이번 배포에서 가능한 것

- DS 실제 두 화면 출력, 아래 화면 터치, 동시 버튼 입력과 스테레오 오디오.
- 세로·가로 DS 화면, 일시 중지·재개, 게임 내 저장 처리와 종료 안내.
- 파일 선택기로 등록하는 로컬 보관함과 기종별 조작 미리보기.
- 본체 프레임·힌지, 눌림·포커스 표시, 시스템 설정을 따르는 진동.
- 밝은·어두운 테마와 큰 글씨 대응.
- 파일 불러오기 취소, 중복·읽기 오류 안내, 원본 파일을 보존하는 앱 내부 캐시.

## 개발 중인 기능

- **3DS는 실험 단계입니다.** 코어와 플레이 화면은 포함하지만 현재 홈브루 검증에서 검은 화면이 발생합니다. 정상 실행을 보장하지 않습니다.
- **Switch·Switch 2 실행 엔진은 아직 앱에 연결되지 않았습니다.** 보관함 등록과 조작 미리보기를 제공합니다.
- Galaxy S23 Ultra를 포함한 실물 기기의 조작감·진동·발열·게임별 성능은 아직 별도 검증이 필요합니다.
- DSi, 퀵세이브, 멀티플레이와 `.cia` 설치는 지원하지 않습니다.

## 저장 데이터와 업데이트

게임 내 저장은 앱 내부에 보관됩니다. 원본 게임 문서는 변경하지 않습니다. 앞으로 이 배포 인증서로 서명한 새 버전은 같은 앱의 업데이트로 설치할 수 있습니다.

이전 GitHub Actions 개발 APK를 설치했다면 서명이 달라 이번 APK로 바로 업데이트되지 않을 수 있습니다. **앱을 삭제하면 앱 내부 세이브도 지워집니다.** 기존 저장 데이터를 먼저 백업하고 보존한 상태에서 설치 경로를 확인하세요.

## 검증과 소스

배포용 APK의 서명·버전·ABI·16KB 정렬, 린트와 모델·캐시 검사를 수행합니다. 배포용 앱과 같은 인증서의 테스트 APK로 DS 화면·입력·종료·재실행을 확인한 뒤 이 릴리스를 게시합니다. 에뮬레이터 검증과 실물 기기 검증은 별도입니다.

Assets에 APK 체크섬, 빌드·소스 매니페스트, 공개 서명 인증서, 서드파티 고지와 대응 소스를 함께 제공합니다. 정확한 소스 커밋과 코어 핀은 매니페스트를 확인하세요.

게임·닌텐도 BIOS·펌웨어·키는 번들하지 않습니다. 앱과 포함 코어의 소스·패치·빌드 방법은 저장소 및 대응 소스 묶음에 포함합니다.
