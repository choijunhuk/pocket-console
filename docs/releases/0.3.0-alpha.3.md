# Pocket Console 0.3.0-alpha.3 — 전체화면과 화면 배치

DS·3DS 플레이어에 전체화면과 주 화면 확대를 추가했습니다. 두 화면을 작게 나눠 보는 대신 게임에 맞는 배치를 고를 수 있습니다.

## 사용 방법

1. 플레이어 상단의 **전체화면**을 누릅니다.
2. **메뉴 → 화면 배치**에서 **화면 둘 다**, **큰 주 화면 + 보조 화면**, **주 화면만**을 선택합니다.
3. **위/아래 화면 바꾸기**로 원하는 화면을 크게 봅니다. 아래 화면은 크기·위치가 바뀌어도 터치할 수 있습니다.
4. **버튼 숨기기/보이기**로 게임 공간을 확보합니다. 메뉴 버튼은 유지됩니다.

Android 뒤로 가기는 먼저 전체화면을 해제합니다. 게임을 끝내려면 메뉴의 **라이브러리로 나가기**를 선택합니다. 화면 배치·교체·전체화면·버튼 표시 설정은 기종별로 기억합니다.

화면 폭의 기존 360/400dp 제한을 제거했습니다. 자동 배치는 두 화면이 더 크게 들어가는 방향을 선택하고, 원래 화면 비율을 유지합니다. 전체화면에서도 로딩·오류·저장 마무리 안내는 표시합니다.

## 설치와 업데이트

Assets의 `PocketConsole-v0.3.0-alpha.3.apk`를 다운로드해 설치합니다. 비공개 저장소 접근 권한이 있는 GitHub 로그인이 필요합니다. Android 8.0 이상 ARM64/x86_64가 대상입니다.

이전 공식 알파와 같은 인증서, 버전 코드 6으로 서명합니다. 업데이트할 때 앱을 삭제할 필요가 없습니다. **앱 삭제는 내부 세이브를 지우므로 주의하세요.** 개발 APK는 서명이 다를 수 있습니다.

## 검증 범위

API36 ARM64 16KB 가상 기기에서 실제 DS 화면·오디오·동시 버튼·터치 변환·화면 교체·뒤로 가기·종료·재실행을 검사했습니다. 360×640/640×360dp, 글씨 1.3배, 밝은·어두운 화면의 캡처를 확인했습니다. 3DS는 게임을 열지 않는 UI 배치·버튼·오류 경로 검사를 별도로 수행했습니다.

3DS 호스트의 실제 화면·입력·오디오 검사는 유지하지만, Android 3DS 실행과 Galaxy S23 Ultra를 포함한 실물 기기의 성능·진동·게임별 호환성은 미검증입니다. 3DS는 GLES 3.2가 필요합니다. Switch·Switch 2 실행 엔진은 이번 APK에 포함하지 않습니다.

## 배포 파일

서명·버전·ABI·16KB 정렬, 린트·모델·캐시, 실제 코어 및 Android 릴리스 검사를 통과한 뒤 게시합니다. APK, 체크섬, 빌드 매니페스트, 공개 인증서, 서드파티 고지와 대응 소스를 제공합니다. 게임·닌텐도 BIOS·펌웨어·키는 번들하지 않습니다.
